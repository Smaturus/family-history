# Семейный архив

Статический сайт семейной истории: единый локальный YAML-источник, редактируемые тексты и генератор HTML с двумя SVG-древами.

Главная страница — обложка: первый экран, краткая заметка об основателе и входы в разделы «Матюхины» и «Скиба». В основной навигации есть поиск по публичному архиву. У каждого раздела пять компактных пунктов: «Ветви», «Древо», «Люди», «Документы» и «Места»; текущий пункт выделяется и получает `aria-current`. Географический указатель раскрывает ссылки на связанные карточки и документы без биографических описаний пунктов. Обычная биографическая хроника не публикуется отдельной страницей, а прежние ссылки `-timeline` ведут к документам раздела. Супруг и общие потомки остаются на обоих древах, но предки супруга не дублируются. Карточка персоны открывается по `#person-` и существующему id. Для прямого доступа также используются ссылки `#matyukhiny`, `#skiba`, `#matyukhiny-tree` и `#skiba-tree`.

Каждое SVG-древо сохраняет свой поиск, кнопки масштаба, вписывание и возврат к исходному виду. На телефоне работает жест двумя пальцами, на всех устройствах — двухосевое перемещение. В выдачу поиска попадают только имена и публичные даты.

Фотографии задаются в `gallery.photos` каждого раздела. Пустая галерея не создаёт публичных блоков и пунктов навигации.

## Локальная работа

```powershell
python -m pip install -r requirements.txt
python scripts/build_site.py
python -m http.server 8000
```

После запуска сервера сайт доступен по адресу `http://localhost:8000`.

Проверки:

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest tests/ -q
```

## Файлы

- `data/family.yaml` — генеалогические данные; каталог `data/` игнорируется Git и не публикуется.
- `content/content.yaml` — публичные тексты и структура разделов.
- `scripts/build_site.py` — сборка `index.html` и проверка приватности.
- `scripts/parse_data.py` — загрузка и валидация данных.
- `assets/site.css` — стили, встраиваемые в HTML при сборке.
- `tests/` — тесты и синтетическая фикстура для CI.
- `docs/architecture.md` — архитектура и правила публикации.

Файл `.nojekyll` отключает обработку Jekyll на GitHub Pages.

Для ныне живущих публикуются только имя и год рождения. Реальные данные не попадают в Git или Actions: автоматическая проверка сборки использует `tests/fixtures/minimal.yaml`.

Подробности — в [docs/architecture.md](docs/architecture.md).
